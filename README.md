### 功能介绍

* 搜片神器，高清党福音
* 自动解析电影名称/豆瓣ID/IMDb ID
* BTDigg/SubHD/字幕库/伪射手 一键直达
* BT 搜索默认清晰度 1080p / 2160p 面板内一键切换，偏好自动记忆
* 片名或 ID 解析不到的入口自动置灰，不生成废链接

### 使用说明

* 建议使用暴力猴 Violentmonkey 安装
* BTDigg 需代理访问
* 清晰度偏好存在豆瓣域 localStorage，换浏览器或清缓存后需重设
* 个别电影名称复杂或者有多个名称，解析的名称可能不准确
